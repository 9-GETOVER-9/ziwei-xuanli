# 紫微玄历

一个可离线打开的道教神仙圣诞与斋期网页原型。打开 `index.html` 会先看到当天的农历日期、已收录的圣诞和其他纪念日；顶部可切换到月历与紫微神系图。原始单文件版本保留在 `daojiao_calendar_prototype.html`，便于对照。

## 当前内容边界

- 圣诞与斋期采用现有历例和页面内规则，仍需逐项校核来源与跨浏览器日期结果。
- 月历日期侧栏与今日页会展示已找到的对应宝诰，逐篇标明版本出处。四御文本保留先前所据[中国道教协会《诸真宝诰》](https://taoist.org.cn/getDjzsById.do?id=1198)版本，南极一篇本轮改据道教文化中心所录《诸师真诰》版本；其他文本来自页面所列道教文库或宫观等来源，存在科本异文。独立宝诰暂缺时，页面会说明原因，不把另一位神仙的宝诰冒充专属文本。
- 九皇斋期九天按北斗七星及左辅、右弼依次标示；这是页面采用的一种九皇说法，九日并非每位星君仅在对应日下降。日期侧栏说明另一种“天皇、紫微与北斗七星”说法。九日共用《北斗宝诰》，并明确标为相关总诰。
- 宝诰目录由 `baogao-catalog.js` 随网页一并加载，离线打开仍可阅读。`scripts/build-baogao-catalog.py` 用于按已列来源重新生成目录，并同步更新网页中的目录版本标识，需要联网及 Python 的 `requests`、`beautifulsoup4`；普通浏览不需要构建。
- 2026-10-03按实际公历日期复核：2026 年有119条神仙相关纪念，114条显示专属或明确标注关系的文本；北方五道、刘渊然、华佗、二郎真君、东皇大帝五项仍需核定身份或原文。旧统计重复计入跨月日期，已订正。详见[宝诰复核记录](docs/baogao-review-2026-10-03.md)。
- 本轮补充了正文边界、多版本与展示一致性的检查：`node tests/smoke.cjs`、`node tests/baogao-audit.cjs`、`python tests/catalog-extraction.py`。
- 神像图片尚未选定，首页保留图片区。
- `index.html` 不需要构建工具，可直接用现代浏览器打开。若要启动本地预览，可在项目目录运行 `python -m http.server 8765`，再访问 `http://127.0.0.1:8765/`。
