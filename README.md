# 紫微玄历 · 道教神仙圣诞与斋期日历

**从今天开始，沿着农历认识神仙圣诞、斋期与星辰神系。**

一个可以直接在浏览器中打开的道教文化日历原型。首页看今日圣诞，月历查节期与相关宝诰，紫微神系图帮助读者理解神仙之间的关系。

`今日圣诞` · `农历月历` · `紫微神系` · `宝诰阅读` · `离线可用` · `无需构建`

---

## 它能做什么

| 入口 | 你能看到什么 |
| --- | --- |
| **今日** | 当天的公历、农历、主要圣诞、其他纪念日，以及已收录的相关宝诰。 |
| **月历** | 按月浏览神仙圣诞、斋期和节日；点击日期查看事件详情。 |
| **搜索** | 按神仙名称、神号、别名或节日查找内容。 |
| **紫微神系** | 以中天紫微北极大帝为中心，探索四御、北极四圣、斗姥等相关神系。 |
| **宝诰目录** | 按农历月份打开已收录神仙纪念的图文阅读页，查看对应文本、拼音初稿与出处。 |
| **神仙资料** | 阅读称号、简介、传统日期、相关经典、宫观及神系关系。 |
| **宝诰** | 在对应日期阅读已收录文本，并查看所据版本或来源链接；总诰与专属宝诰分别标注。 |
| **图文宝诰页** | 首批 6 位北极相关神仙配有原创风格化画像；详情页左侧是画像与简介，右侧是宝诰及出处。 |

> 这是一份可浏览、可继续校订的文化日历。不同道派、经典和科本的神号、日期与宝诰可能存在异文，页面会尽量标明采用的历例和文本版本。

## 快速体验

1. 下载或克隆仓库：

   ```bash
   git clone https://github.com/9-GETOVER-9/ziwei-xuanli.git
   ```

2. 打开仓库中的 `index.html`，即可在现代浏览器中使用。无需安装依赖，也无需联网运行。
3. 在顶部切换 **今日 / 月历 / 紫微神系**；需要查找具体神仙或节日时，使用搜索框。

从今日卡片、月历日期侧栏、紫微神系图或宝诰目录打开神仙详情，可进入独立的图文阅读视图。现有 105 条已收录文本的神仙纪念可打开对应阅读页；15 位资料库神仙配有原创风格化画像，其他页面暂以明确标注的待补画像区域呈现。现有宝诰配有逐字拼音初稿；读音与断句将在标准版提供后继续核对。神像不是历史画像或传统定本。

如果希望通过本地地址预览，可在项目目录运行：

```bash
python -m http.server 8765
```

然后访问 `http://127.0.0.1:8765/`。

## 从日期到神系，怎么读

```text
今天有什么圣诞？
        ↓
打开「今日」，阅读当天的主要事件与宝诰
        ↓
进入「月历」，查看前后日期、斋期和相关节日
        ↓
搜索神仙名称，或从「紫微神系」进入人物资料
```

## 内容与校订说明

- 固定农历日期按项目采用的历例录入；八会、八节、明戊、暗戊与天赦由页面内规则生成。
- 月历覆盖 **1900—2100 年**，农历换算使用浏览器内置的 Chinese Calendar（`Intl`）。跨浏览器日期结果仍需逐项校核。
- 宝诰随 `baogao-catalog.js` 一起加载，因此离线打开也能阅读。页面对文本版本及相关总诰作出标注；暂未核实的专属文本不会用其他神仙的宝诰代替。
- 紫微神系图用于科普导航。不同传统中的神系关系可能有差异，图中不把相近称谓直接视为同一神格。
- 截至 **2026-10-03** 的复核记录：2026 年收录 119 条神仙相关纪念，其中 114 条显示专属文本或明确标注关系的文本；仍有 5 项待核定身份或原文。详见 [宝诰复核记录](docs/baogao-review-2026-10-03.md)。

## 项目结构

```text
ziwei-xuanli/
├── index.html                        # 当前网页入口：今日、月历、神系图
├── baogao-catalog.js                # 随页面加载的宝诰目录
├── daojiao_calendar_prototype.html  # 保留的早期单文件原型
├── docs/                             # 校订记录、协作规则与设计说明
├── scripts/build-baogao-catalog.py   # 按已列来源重建宝诰目录
└── tests/                            # 页面与目录检查
```

普通浏览只需打开 `index.html`。重建宝诰目录需要联网，以及 Python 的 `requests`、`beautifulsoup4`；它不是使用网页的前置步骤。
